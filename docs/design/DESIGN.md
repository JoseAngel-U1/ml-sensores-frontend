## Brand & Style
This design system defines an elite cyber-athletic biomechanics and performance telemetry interface. The aesthetic bridges high-performance sports science, precision bio-wearable telemetry, and machine-learning diagnostics into an ultra-clean, clinical-grade light mode.

The personality balances surgical precision with kinetic dynamism: analytical, responsive, frictionless, and rigorous. It strips away ornamental noise in favor of data density, real-time kinetic visualizers, and immediate biometric legibility.

Key stylistic pillars:
- **Kinetic Minimalism:** High-contrast data readouts against airy, clinical surfaces.
- **Instrument-Grade Structure:** Modular information cards, crisp micro-borders, and engineered data clusters mimicking avionics and athletic lab equipment.
- **Dynamic Visual Feedback:** Calculated bio-green pulses, numeric tickers, and crisp status pings indicating machine learning pipeline confidence and real-time sensor streams.

## Colors
The color architecture relies on a specialized high-clarity light theme designed for outdoor sunlight visibility, high-speed scanning, and optical fatigue reduction during intense training and diagnostic sessions.

### Functional Palette
- **Canvas Base (`#F5F8F5`):** A pale, desaturated mint-neutral canvas that prevents optic glare while maintaining high luminance contrast.
- **Surfaces & Cards (`#FFFFFF`):** Pure white modular elevation planes that isolate telemetry streams, sensor arrays, and metric groups.
- **Primary Kinetic Accent (`#16854B`):** A dense, energetic forest-emerald hue applied exclusively to interactive primitives, active telemetry channels, focus rings, and primary action triggers.
- **Soft Bio-Container (`#E4F3E9`):** A muted, luminous green tint dedicated to inactive pill badges, data chip fills, graph fills, and subtle telemetry alert bounds.
- **Deep Signal Neutral (`#172C20`):** An obsidian-pine shade for core telemetry values, headers, and mission-critical metrics. Yields a strict WCAG AAA contrast ratio on white.
- **Secondary Metric Neutral (`#506557`):** Calibrated for secondary metadata, dimensional units (e.g., `bpm`, `ms`, `W/kg`), graph grid-lines, and inactive states.

## Typography
Typography is split into two specialized engines:
1. **Space Grotesk (Human Layer):** Modern, geometric, and dynamic. Delivers athletic momentum across titles, narrative ML insights, section headings, and qualitative evaluations.
2. **JetBrains Mono (Telemetry Layer):** Strict, fixed-width machine readouts for numeric metrics, timestamps, latency counts, confidence scores, and raw sensor channels. Prevents jitter during real-time scalar shifts.

### Rules for Application
- Display metric values must strictly use `font-variant-numeric: tabular-nums` or rely directly on `JetBrains Mono`.
- All `label-*` tiers enforce uppercase tracking for high-velocity peripheral readability.
- Units (e.g., `HZ`, `VO2_MAX`, `MS`) trailing numerical values must be styled 2 sizes smaller in `text_secondary_color_hex` to ensure value hierarchy.

## Layout & Spacing
The layout adheres to an engineering dashboard grid calibrated for real-time telemetry streaming and dense spatial efficiency.

### Grid & Architecture
- **Desktop (1200px+):** 12-column layout with `1.5rem` gutters and `2.5rem` outer canvas boundaries. Maximum container width capped at `1440px` to maintain optimal peripheral scanning.
- **Tablet (768px – 1199px):** 8-column layout with `1rem` gutters and `1.5rem` margins. Sensor matrix cards collapse to 2-column arrays.
- **Mobile (< 768px):** 4-column layout with `1rem` gutters and `1rem` margins. Live charts and stream channels switch into vertical single-column stacks with persistent top metric summaries.

### Spatial Rhythm
- Internal card padding defaults strictly to `space-md` (16px) or `space-lg` (24px) for focal telemetry widgets.
- Micro-clustering of sensor labels and corresponding metrics uses `space-2xs` (4px) to create immediate visual coupling.

## Elevation & Depth
Elevation mimics precision lab equipment: flat, mechanical, and layered via micro-borders and subtle ambient diffusion rather than heavy theatrical shadows.

### Elevation Levels
- **Level 0 (Canvas Base):** Flat `#F5F8F5` surface. Used for the overall viewport background.
- **Level 1 (Card & Module Layer):** Pure `#FFFFFF` background bound by a 1px border of `#DCE7DF`. No shadow or a microscopic ambient shadow: `box-shadow: 0 1px 3px rgba(23, 44, 32, 0.04)`.
- **Level 2 (Hover / Active Module):** Crisp `#FFFFFF` surface lifted with `box-shadow: 0 4px 12px rgba(22, 133, 75, 0.08)` and border transition to `#16854B` at 30% alpha.
- **Level 3 (Floating HUD / Overlays / Flyouts):** Pure `#FFFFFF` with an active boundary: `box-shadow: 0 12px 32px rgba(23, 44, 32, 0.08), 0 2px 4px rgba(22, 133, 75, 0.04)`.

### Border Discipline
Rely heavily on structural borders (`1px solid #DCE7DF`) over blur effects to maintain an authentic tactical hardware display feeling.

## Shapes
The design system adopts a calibrated **Soft (Tier 1)** shape language to project mechanical precision without appearing hostile. Rounded corners soften the dense data presentation while maintaining the clean geometry of medical and athletic testing monitors.

### Geometry Specifications
- **Standard UI Elements & Inputs:** `4px` (`0.25rem`) border-radius for inputs, buttons, and individual telemetry meters.
- **Cards & Data Modules:** `8px` (`0.5rem`) for telemetry panels, waveform viewports, and ML anomaly alert containers.
- **Status Pills & Micro Indicators:** Pill radius (`9999px`) reserved strictly for live state indicators, sensor status indicators (e.g., `CONNECTED`, `SYNCING`), and micro stream tags.

## Components

### Buttons
- **Primary Kinetic:** Background `#16854B`, text `#FFFFFF`, radius `4px`, font `Space Grotesk` weight 600. Hover state darkens background to `#0D532E` with a subtle elevation shift. Active state applies `scale(0.98)`.
- **Secondary Telemetry:** Background `#E4F3E9`, text `#16854B`, border `1px solid transparent`. Hover transitions border to `#16854B`.
- **Ghost / Outlined:** Background transparent, border `1px solid #DCE7DF`, text `#172C20`. Hover background `#F5F8F5`.

### Chips & Sensor Badges
- **Status Chip:** Background `#E4F3E9`, text `#16854B`, font `JetBrains Mono` 11px uppercase, padding `4px 8px`, border-radius `9999px`.
- **Live Stream Indicator:** Includes a 6px circular dot pulsating via CSS keyframes (`#16854B`) with a soft aura glow.
- **Warning / Out-of-Bounds:** Background `#FEECEB`, text `#B42318`, border `1px solid #FECDCA`.

### Cards & Telemetry Containers
- **Default Card:** Surface `#FFFFFF`, border `1px solid #DCE7DF`, border-radius `8px`, padding `16px` to `24px`.
- **Data Section Header:** Includes a monospaced section coordinate (e.g., `[CH_04 // EMG]`) in `JetBrains Mono` 10px, colored `#506557`, aligned to the top-right corner.

### Form Inputs & Adjusters
- **Text & Numeric Field:** Surface `#FFFFFF`, border `1px solid #DCE7DF`, text `#172C20`, radius `4px`.
- **Focus State:** Border changes to `1px solid #16854B`, with an outer ring `0 0 0 2px rgba(22, 133, 75, 0.15)`. No default browser outlines.
- **Monospaced Value Fields:** Sensor threshold tuning fields must display metrics in `JetBrains Mono`.

### Checkboxes & Toggle Switches
- **Checkbox:** Square `16px` by `16px`, radius `3px`, border `1px solid #506557`. When checked, background fills with `#16854B`, displaying a crisp white SVG check.
- **Toggle Switch:** Capsule track `36px` by `20px` in `#DCE7DF`. Active track shifts to `#16854B`. Switch thumb is `#FFFFFF` with smooth `150ms ease-out` sliding transition.

### Lists & Telemetry Logs
- Alternating subtle rows (`#FFFFFF` to `#FAFDFB`) with hairline borders (`1px solid #F0F4F1`).
- Numbers, timestamps, and confidence percentages align strictly to the right using `JetBrains Mono`.

### Domain-Specific Components
- **ML Confidence Bar:** A ultra-thin `4px` segmented horizontal bar showing model inference accuracy. Unfilled segments in `#E4F3E9`, active segments in `#16854B`.
- **Sensor Sparkline Container:** Integrated lightweight SVG mini-charts with line color `#16854B` (stroke-width: `1.5px`) and an area fill gradient fading down from `#E4F3E9` (40% opacity) to completely transparent.
